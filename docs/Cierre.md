# Demo y cierre de la entrega

## Demo con el usuario

Realizarla sobre la URL desplegada y con datos ficticios. Registrar fecha efectiva, participantes, versión mostrada, comentarios y decisión del contacto. El aval al mockup de Entrega 2 no equivale a aceptación de la aplicación.

| Caso | Resultado que se debe observar |
|---|---|
| Centro | Coordinador registra y técnico consulta; código duplicado rechazado |
| Evento y persistencia | Guardar, recargar, filtrar; repetir el mismo evento sin otra fila |
| Estados y episodios | Silencio no implica corte; otro LOW no reinicia el corte; HIGH cierra el episodio |
| Criticidad | Ajustar umbrales como coordinador; técnico no puede guardarlos |
| Verificación | Registrar diagnóstico; no aceptar evento de otro centro ni cierre sin resultado |
| Borrador | Exigir confirmación humana; conservar referencia de prueba sin enviar a Aranda |
| Cierre de sesión | Impedir acceso autenticado después de salir |

Por cada caso guardar resultado real, observación, ajuste y evidencia. No completar una aceptación antes de realizarla.
